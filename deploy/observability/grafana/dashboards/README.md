# Dashboards

O provedor do Grafana lê os arquivos JSON desta pasta. Os cinco dashboards da tarefa 4.6 entram aqui:

- `rag-performance.json`
- `llm-observability.json`
- `retrieval-analytics.json`
- `infrastructure.json`
- `workflow-monitoring.json`

Cada arquivo tem `uid` fixo e `title` igual ao nome do arquivo. O `uid` fica estável para os links entre os dashboards.
